지표 설명
순위
표의 열 이름을 누르면 그 지표로 순위가 다시 매겨집니다. 기본은 정확도 R@1, 속도 1000장 처리 시간입니다. 값이 같으면 같은 순위입니다.
coarse / fine
coarse는 같은 카테고리면 정답, fine은 카테고리와 속성이 모두 같아야 정답입니다.
R@1 · R@10
1위(또는 10위 안)에 정답이 하나라도 있는 쿼리의 비율입니다.
mAP@10
10위까지의 정답 순서를 함께 보는 점수입니다. 상위에 정답이 많이 몰릴수록 높습니다.
DreamSim 대비
쿼리마다 AP@10을 DreamSim과 비교해 더 높은(승)·같은(무)·낮은(패) 쿼리 수입니다.
1000장 처리
전처리부터 임베딩까지 1,000장을 처리하는 시간입니다(갤러리 색인 비용). 배수는 DreamSim 대비입니다.
쿼리 1장
사용자가 올린 이미지 한 장을 임베딩하는 시간(batch 1)입니다. 검색 응답 시간에 그대로 더해집니다.
이미지 토큰
이미지 한 장이 모델 안에서 몇 개 토큰이 되는지입니다. ViT 계열은 패치 수(백본이 여럿이면 합계), VLM 계열(Qwen3-VL, WeMM)은 언어 모델에 들어가는 길이이며 원본 해상도를 따라가 이미지마다 다릅니다(평균).
인덱스
갤러리 6만 장의 임베딩을 float32로 저장했을 때 크기입니다.
